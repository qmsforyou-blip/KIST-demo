# КИСТ — учебное демо UI027

Статический макет рабочих мест. Все заявки, номера заказов, количества и сведения об исполнении в публичной версии учебные. Данные реальных заявок Б24 не включены.

Изменения хранятся в браузере посетителя. Общая база, реальная авторизация и интеграции не подключены.

Извещение на изменение: 0270+161026. Основной проект KIST остаётся приватным.

Добавлены две учебные очереди анализа качества, карточки D0–D8 и предлагаемые сроки.

В M07-1 индикатор заказа зелёный по умолчанию и красный, если до договорного срока меньше 14 календарных дней (или срок уже наступил).

UI027: Термист → Паспорта / садки (M05-16). Паспорта трёх синтетических ящиков, общий запуск, ручное подтверждение/исправление загрузки и выгрузки, замеры/повторы, поздняя проверка и факт передачи. JSON-архив хранится только в браузере; сервер/ОВЕН/команды печи не подключены. Ровно 14 дней до срока — зелёный индикатор.
