# КИСТ — учебное демо UI028

Статический макет рабочих мест. Все заявки, номера заказов, количества и сведения об исполнении в публичной версии учебные. Данные реальных заявок Б24 не включены.

Изменения хранятся в браузере посетителя. Общая база, реальная авторизация и интеграции не подключены.

Извещение на изменение: 0271+161026. Основной проект KIST остаётся приватным.

Добавлены две учебные очереди анализа качества, карточки D0–D8 и предлагаемые сроки.

В M07-1 индикатор заказа зелёный по умолчанию и красный, если до договорного срока меньше 14 календарных дней (или срок уже наступил).

UI028: Термист → Паспорта / садки (M05-16). Паспорта трёх синтетических ящиков, общий запуск, ручное подтверждение/исправление загрузки и выгрузки, замеры/повторы, поздняя проверка и факт передачи. JSON-архив хранится только в браузере; сервер/ОВЕН/команды печи не подключены. Ровно 14 дней до срока — зелёный индикатор.

UI028: очередь термиста сортируется по заказу-позиции/сплаву; Предложение загрузки — вторая вкладка. Добавить из плана → позиции/остатки без дублей → Новая садка по сплаву/режиму и фактическим ящикам. ПК/телефон: адаптивные диалоги/карточки; последовательный перенос очереди/паспортов JSON, общей синхронизации нет. Режимы и совместимость не назначаются автоматически.
